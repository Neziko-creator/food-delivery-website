🦀 Красти Крабс — ресторан из Бикини-Боттом

Добро пожаловать на сайт легендарного ресторана «Красти Крабс»!

Это учебный веб-проект, созданный по мотивам мультсериала «Губка Боб Квадратные Штаны». Сайт выполнен в современном морском стиле с элементами атмосферы подводного мира.

🌊 О проекте

Сайт представляет собой виртуальную страницу ресторана, где посетители могут познакомиться с меню и добавить понравившиеся блюда в корзину.

🍔 Основные возможности

* Главная страница с оформлением в морском стиле.
* Меню с популярными блюдами ресторана.
* Карточки блюд с названиями и ценами.
* Добавление блюд в корзину.
* Изменение количества выбранных товаров.
* Автоматический подсчёт стоимости заказа.
* Компактная корзина с возможностью открытия и закрытия.
* Счётчик выбранных блюд.

🛠 Используемые технологии

* HTML5 — структура сайта.
* CSS3 — оформление и адаптивный дизайн.
* JavaScript — интерактивность и работа корзины.

🎨 Дизайн

В оформлении используются морские оттенки, бирюзовый, песочный и коралловый цвета. Главная задача дизайна — передать атмосферу подводного ресторана, сохранив современный и удобный интерфейс.

📌 Цель проекта

Практическое изучение веб-разработки, создание пользовательского интерфейса и освоение основ HTML, CSS и JavaScript.
